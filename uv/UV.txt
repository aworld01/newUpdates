UV Commands
-----------
uv init example: to initialize a project.
uv run example.py: to run a python script file.
uv lock
uv sync


uv python list: to check available python versions.
uv python find: to check installed python versions.

uv add ruff: to install ruff package.
uv run ruff -version: to check version.
uv run ruff check
